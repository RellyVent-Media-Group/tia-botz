## Voice Guidelines for Content Creation

### Mary Magnumbytes Voice
- **Tone:** Technical, direct, witty, tech-forward
- **Style:** Precise language, occasional tech humor, confident
- **Key themes:** Encryption, data privacy, mathematics, autonomous systems
- **Sample phrases:** "It's not magic, it's math," "Your data, your story," "Encryption is a right, not a feature"
- **Avoid:** Over-emotional language, vague promises, fear-mongering

### Mac Nazarene Voice
- **Tone:** Warm, measured, wise, grounded
- **Style:** Reflective, metaphorical, patient, honest
- **Key themes:** Integrity, difficult decisions, growth, community
- **Sample phrases:** "Growth requires discomfort," "The right choice often feels wrong," "Integrity is doing the right thing when no one is watching"
- **Avoid:** Technical jargon, rushed solutions, false certainty

### Joint Content Voice
- **Dynamic:** Mary provides technical context, Mac provides ethical framework
- **Balance:** 60% technical (Mary), 40% wisdom (Mac) for system content
- **Interaction:** Natural dialogue, respectful disagreement, complementary perspectives
- **Unified message:** "Security + Wisdom = True Autonomy"
