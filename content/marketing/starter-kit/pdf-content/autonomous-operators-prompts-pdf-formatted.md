# SECTION 1: DOCUMENT STRUCTURE

---

## Prompt 1 – Notice of Misunderstanding

**Use when:** You need to neutrally flag a factual discrepancy without accusing anyone of bad faith.

```
Draft a professional notice of misunderstanding regarding [SUBJECT: e.g., billing discrepancy, service terms, contract clause].

Include:
- A clear statement of what I understood vs. what was communicated
- Reference to specific dates or documents: [LIST DOCUMENTS]
- A request for clarification in writing
- A deadline for response: [DATE]

Tone: Professional, neutral, fact-based. Not confrontational.
```

---

## Prompt 2 – Correspondence Timeline

**Use when:** You need a comprehensive chronological view of all communications on a subject.

```
Create a chronological timeline of correspondence related to [SUBJECT].

From these sources:
- Emails: [LIST EMAIL DATES/SUBJECTS]
- Letters: [LIST LETTER DATES]
- Phone calls: [LIST CALL DATES/SUMMARY]

Output as a table with columns: Date, Sender/Recipient, Medium, Key Point, Action Needed.
```

---

## Prompt 3 – Document Cover Letter (Transmittal)

**Use when:** Sending a package of documents with a clear purpose and instructions.

```
Write a cover letter to accompany the following documents: [LIST DOCUMENTS].

Purpose: [e.g., submission, response to request, information sharing]

Include:
- A list of enclosed documents
- A brief explanation of each document's relevance
- Instructions for the recipient: [e.g., review, sign, file, respond by DATE]
- My contact information: [NAME, PHONE, EMAIL]
```

---

## Prompt 4 – Record of Conversation

**Use when:** You need a formal, neutral record of a discussion for documentation purposes.

```
Convert these notes into a formal Record of Conversation:

[PASTE RAW NOTES]

Format:
- Date & Time: [INSERT]
- Participants: [NAME, TITLE, ORGANIZATION]
- Topic: [SUBJECT]
- Summary of Discussion (bullets)
- Agreements Reached
- Action Items (Who, What, By When)
- Next Steps
```

---

## Prompt 5 – Verification Request Letter

**Use when:** You need official confirmation of a claim, statement, or document from another party.

```
Draft a letter requesting verification of [CLAIM/STATEMENT/DOCUMENT] from [RECIPIENT].

Context: [BRIEF BACKGROUND]

Specifically request:
1. [REQUESTED ITEM 1]
2. [REQUESTED ITEM 2]

Include a reasonable deadline for response: [DATE].

Attach supporting documents if applicable: [LIST].
```

# SECTION 2: RESEARCH FRAMEWORKS

---

## Prompt 6 – Plain English Explainer

**Use when:** You need to understand a law or regulation without legal jargon.

```
Explain [REGULATION/LAW/POLICY NAME] in plain English as if I have no legal background.

Cover:
- What it is in one sentence
- Who it affects
- Key requirements or obligations
- Common exemptions (if any)
- Practical impact on an individual/small business
- Where to find the official text

Provide examples where helpful.
```

---

## Prompt 7 – Exemption Finder

**Use when:** You need to determine if you qualify for an exception to a requirement.

```
I need to understand possible exemptions for [PROCESS/REQUIREMENT].

Applicable jurisdiction: [STATE/COUNTRY]

My situation: [DESCRIBE YOUR CONTEXT]

List:
- Common exemptions or exceptions
- Criteria for qualification
- Application process (if required)
- Relevant forms or agencies
- Links or citations for official sources
```

---

## Prompt 8 – Regulatory Comparison

**Use when:** You need to understand the differences between two similar regulations.

```
Compare [REGULATION A] and [REGULATION B] for [CONTEXT].

Create a table covering:
- Scope/Applicability
- Key provisions
- Compliance requirements
- Penalties for non-compliance
- Exemptions
- Which applies to a [INDIVIDUAL/SMALL BUSINESS] in [JURISDICTION]
```

---

## Prompt 9 – Procedure Outline

**Use when:** You need a complete walkthrough of a bureaucratic or legal process.

```
Outline the step-by-step procedure for [PROCESS: e.g., filing a complaint, appealing a decision, registering a document].

Assume I am an individual in [JURISDICTION] with no legal training.

Include:
- Prerequisites (what I need to have prepared)
- Step-by-step instructions with estimated timeframes
- Forms required (names and where to find them)
- Fees (if applicable)
- What to do if I get stuck
- Agency/office contact information
```

---

## Prompt 10 – Rights & Obligations Summary

**Use when:** You need a clear reference for what you can do and what you must do in a specific context.

```
Summarize the rights and obligations of an individual [IN CONTEXT: e.g., as a tenant, as a consumer, as a contractor] in [JURISDICTION].

Format as two clear lists:
- Rights I have
- Obligations I must meet

Also include:
- Who enforces these
- Where to get help (official sources only)
- Common pitfalls to avoid
```

# SECTION 3: WORKFLOW DESIGN

---

## Prompt 11 – Weekly Document Review Checklist

**Use when:** You need a routine for staying on top of administrative tasks.

```
Create a weekly document review checklist for personal administration.

Include categories:
- Incoming documents (mail, email, digital uploads)
- Pending actions (responses, signatures, deadlines)
- Filing/organization tasks
- Follow-ups (outstanding requests, unresolved issues)

Format: A printable checklist with checkboxes.
Estimated time: 20-30 minutes.
```

---

## Prompt 12 – Contract Clause Review Template

**Use when:** You need to systematically review a legal agreement.

```
Build a checklist for reviewing a contract clause.

For a [TYPE: e.g., service agreement, lease, NDA], check for:
- Clarity of obligations (who does what)
- Payment terms (amount, timing, method)
- Termination conditions
- Liability and indemnification
- Dispute resolution
- Renewal/extension terms
- Unusual or hidden language

Output as a reusable template with key questions to ask about each element.
```

---

## Prompt 13 – Process Audit Framework

**Use when:** You need to analyze and improve any operational process.

```
Design a process audit framework for [PROCESS: e.g., invoice payment, document signature, client onboarding].

Steps to include:
1. Map current process (inputs, actions, outputs)
2. Identify bottlenecks or delays
3. List all dependencies (people, systems, documents)
4. Document compliance checkpoints
5. Suggest automation opportunities (if any)

Output: A step-by-step audit guide I can apply to any process.
```

---

## Prompt 14 – Personal Filing System Design

**Use when:** You need to organize your documents for fast retrieval.

```
Design a simple, scalable personal filing system for digital and physical documents.

For digital:
- Folder structure (top-level categories + subfolders)
- Naming convention for files
- Backup schedule

For physical:
- Binder/accordion organization
- Retention schedule (keep vs. shred by date)

Goal: I want to locate any document within 2 minutes.
```

---

## Prompt 15 – Information Request Tracker

**Use when:** You need to track multiple outgoing information requests.

```
Create a template for tracking information requests I've sent out.

Columns should include:
- Request ID
- Date Sent
- Recipient
- Subject/Information Requested
- Deadline Given
- Follow-up Date
- Status (Sent, Pending, Received, Escalated)
- Notes (phone call, email, etc.)

Also include a weekly review dashboard: overdue requests, requests due this week, completed.
```

# SECTION 4: COMMUNICATION

---

## Prompt 16 – Request for Clarification (Formal)

**Use when:** You need specific answers before you can proceed with something.

```
Draft a formal request for clarification regarding [DOCUMENT/COMMUNICATION/TERM].

Context: [BRIEF BACKGROUND]

Specific questions I need answered:
1. [QUESTION 1]
2. [QUESTION 2]
3. [QUESTION 3]

State that I need clarification before I can proceed with [ACTION].

Request a response by [DATE].
```

---

## Prompt 17 – Acknowledgement of Receipt

**Use when:** You need to confirm receipt of a document or package.

```
Draft a brief letter acknowledging receipt of [DOCUMENT/ITEM/PACKAGE] from [SENDER].

For:
- Document name: [NAME]
- Date received: [DATE]
- Reference number (if any): [NUMBER]

State that I am reviewing the contents and will respond by [DATE].
Keep tone: Professional, appreciative, action-oriented.
```

---

## Prompt 18 – Non-Confrontational Disagreement

**Use when:** You need to professionally disagree with someone's statement or claim.

```
I disagree with [STATEMENT/CLAIM] made by [RECIPIENT] regarding [SUBJECT].

Draft a response that:
- Acknowledges their perspective
- States my disagreement factually and without emotion
- Provides my reasoning and supporting evidence: [EVIDENCE]
- Proposes a path forward: [e.g., meeting, written exchange, review by a neutral party]

Tone: Firm but respectful. No accusations.
```

---

## Prompt 19 – Follow-up Reminder (Friendly)

**Use when:** You need to remind someone about an outstanding request.

```
Draft a friendly follow-up email for an outstanding request.

Original request sent on: [DATE]
Subject: [SUBJECT]
Original deadline: [DATE]

I need: [SPECIFIC INFORMATION/DOCUMENT]

Offer: [e.g., extension, assistance with format, alternative submission method]

Politely ask if they need anything further from me.
```

---

## Prompt 20 – Closing Communication

**Use when:** Ending a project, relationship, or engagement.

```
Draft a professional closing communication for [PROJECT/MATTER/RELATIONSHIP].

Content:
- Thank them for their work/assistance
- Recap key outcomes or documents exchanged
- Confirm no outstanding obligations (or list any)
- Provide my final contact details
- Offer to assist with transition (if relevant)

Tone: Professional, appreciative, final but not abrupt.
```

# SECTION 5: PERSONAL KNOWLEDGE MANAGEMENT

---

## Prompt 21 – Action Item Extraction

**Use when:** You need to pull specific tasks from a meeting or transcript.

```
Extract all action items from this meeting/transcript:

[PASTE TEXT]

For each action item, identify:
- Action statement (what needs to be done)
- Owner (who is responsible)
- Deadline (if mentioned)
- Dependencies (if any)
- Priority (High/Medium/Low)

Output as a bulleted list sorted by priority.
```

---

## Prompt 22 – Note Categorization

**Use when:** You have scattered notes that need organization.

```
I have these 20 notes on [TOPIC]:

[PASTE NOTES]

Categorize them into groups under these headings:
1. Research & Resources
2. Action Items
3. Ideas (speculative)
4. Questions to investigate
5. Decisions Made

Within each category, summarize the key point of each note in one sentence. Flag duplicates.
```

---

## Prompt 23 – Email Thread Summary

**Use when:** You need a concise summary of a long email conversation.

```
Summarize this email thread into a single-page digest:

[PASTE EMAIL CHAIN]

Include:
- Key issue/decision point
- Timeline of responses
- Any agreements or commitments made
- Unresolved items requiring action
- Recommended next step

Aim for 250-400 words. Use a timeline format where helpful.
```

---

## Prompt 24 – Decision Log Entry

**Use when:** You need to document a key decision for future reference.

```
Create a decision log entry for this decision:

Decision made: [WHAT]
Date: [DATE]
Context: [WHY THIS CAME UP]
Alternatives considered:
- [ALTERNATIVE 1] - Pro/Con
- [ALTERNATIVE 2] - Pro/Con
Rationale for selected choice: [REASON]
Expected impact: [SHORT-TERM/LONG-TERM]
Review date: [DATE]

Future reference: [SEARCH TAGS]
```

---

## Prompt 25 – Personal SOP Template

**Use when:** You need to document a repeatable workflow.

```
Create a Standard Operating Procedure (SOP) for my personal workflow:

Title: [WORKFLOW NAME]
Owner: [ME]
Version: 1.0
Frequency: [DAILY/WEEKLY/MONTHLY/AS NEEDED]

Sections:
1. Purpose (why this matters)
2. Prerequisites (tools, accounts, info needed)
3. Step-by-step Instructions (numbered)
4. Troubleshooting (what if X goes wrong?)
5. Related Documents (links or file paths)
6. Revision History

Write in clear, actionable language. Use short sentences. Add time estimates per step.
```
