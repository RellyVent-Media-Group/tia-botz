## Section 1: Document Structure (5 Prompts)

### 1. Meeting Summary Template
```
Please create a structured meeting summary from the following notes. Include: 
1. Date, time, and attendees
2. Key decisions made
3. Action items with assigned owners and deadlines
4. Follow-up questions to address
5. Next meeting date if scheduled

[Insert your meeting notes here]
```

### 2. Project Timeline Outline
```
Generate a project timeline for [project name] with the following phases:
1. Research and planning
2. Resource allocation  
3. Execution
4. Review and refinement
5. Final delivery

For each phase, include: estimated duration, key milestones, potential blockers, and success criteria.
```

### 3. Process Documentation Template
```
Create a step-by-step process document for [specific task or workflow]. Include:
- Prerequisites and required tools
- Clear numbered steps
- Common mistakes to avoid
- Time estimates for each step
- Quality checkpoints
```

### 4. Correspondence Tracker Structure
```
Design a tracking spreadsheet structure for managing [type of correspondence - emails, letters, applications]. Include columns for:
- Date sent/received
- Sender/recipient
- Subject/purpose
- Status (pending, responded, resolved)
- Follow-up date
- Reference number
- Notes/outcome
```

### 5. File Organization System
```
Propose a folder and file naming convention for organizing [type of files - documents, media, projects]. Include:
- Main category folders
- Subfolder hierarchy
- Consistent naming format (date, project, version, etc.)
- Archive vs. active file separation
- Backup frequency recommendations
```

```
- Specific request details

- Availability for follow-up discussion
- Appreciation for consideration
```

```
Create a template for requesting clarification on [ambiguous situation or document]. Include:
```
