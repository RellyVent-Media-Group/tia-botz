# Quick-Start Workflow: 90-Minute Batch Production

## The 90-Minute System

| Time | Action | Output |
|------|--------|--------|
| **0–20 min** | Generate 5 MJ images (mix of Mac, Mary, Duo) | 5 character frames |
| **20–50 min** | Run all 5 through Kling (2 versions each) | 10 video clips |
| **50–70 min** | Export, trim to 5–8 seconds, add watermark | 10 finished videos |
| **70–90 min** | Write captions using formula below | 10 captions |

**Total: 10 videos in 90 minutes.**

## Character Consistency Rules

**For Midjourney:**
- Use `--cref [character_ref_url]` to lock faces
- Use `--v 7` for latest version
- Use `--s 750` for consistent stylization
- Keep same aspect ratio across all images: `--ar 9:16` for vertical, `--ar 16:9` for horizontal

**For Kling 2.0:**
- Upload your MJ image as reference
- Add "consistent character, same person, photorealistic" to every video prompt
- Use 4K resolution setting
- Enable "Physics Lock" in advanced settings

**Brand Color Placement:**
- Mac: Warm earth tones (golden hour, wood, leather)
- Mary: Cool tech tones (blue, silver, neon accent)
- Duo: Balance of both palettes
