## Production Workflow

### Asset Creation Pipeline

1. **Planning Phase**
   - Define asset requirements
   - Create brief/prompts
   - Establish timeline
   - Allocate resources

2. **Creation Phase**
   - Generate base images/videos
   - Apply character consistency
   - Add text overlays
   - Format for platforms

3. **Review Phase**
   - Quality check against requirements
   - Brand consistency verification
   - Platform compliance check
   - Stakeholder approval

4. **Finalization Phase**
   - Final file optimization
   - Proper file naming
   - Folder organization
   - Backup and archive

**90-Minute Asset Production:**
- 0-20 min: Generate base character images
- 20-40 min: Create platform-specific variations
