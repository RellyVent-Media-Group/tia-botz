# SOP: Custom Character Development

**Title:** Custom Character Development for Fiverr Clients
**Owner:** [ME]
**Version:** 1.0
**Frequency:** AS NEEDED (per client order)

---

## 1. Purpose
Deliver consistent, professional character prompt systems for Fiverr clients using the Mac & Mary framework.

---

## 2. Prerequisites
- Notion workspace with Character Database imported
- Fiverr account with "Custom Character Development" gig active
- Access to Mac & Mary Prompt Vault for reference
- Client brief from Fiverr order
- Text editor (VS Code or Notion)

---

## 3. Step-by-Step Instructions

### Phase 1: Client Brief Analysis (5-10 minutes)
1. Read client brief carefully
2. Identify character archetype, visual style, and use case
3. Note any specific requirements (scenarios, platforms, budget)
4. Ask clarifying questions if brief is unclear
5. **Time estimate:** 10 minutes

### Phase 2: Notion Character Entry (10-15 minutes)
1. Open Notion Character Database
2. Create new character entry
3. Fill in required fields:
   - Name
   - Description
   - Archetype
   - Key Tool Category
   - Allocated Budget
4. Set Status to "In Progress"
5. **Time estimate:** 15 minutes

### Phase 3: Prompt Development (30-45 minutes)
1. Reference Mac Nazarene and Mary Magnumbytes entries for structure
2. Write Classic Hook Prompt (first impression portrait)
3. Write Trust Warmth Prompt (approachable version)
4. Write Hero Branding Prompt (monumental brand shot)
5. Ensure all prompts are 100-150 words with specific directions
6. **Time estimate:** 45 minutes

### Phase 4: Consistency Rules (15-20 minutes)
1. Document character consistency rules
2. Define brand color palette (hex codes)
3. Specify wardrobe, expression, and lighting guidelines
4. Create usage notes for different AI tools
5. **Time estimate:** 20 minutes

### Phase 5: Delivery Package (10-15 minutes)
1. Export character entry as PDF from Notion
2. Create Markdown file with all prompts
3. Package with consistency rules and brand colors
4. Upload to Fiverr delivery
5. Send delivery message with usage tips
6. **Time estimate:** 15 minutes

---

## 4. Troubleshooting

**Problem:** Client brief is too vague
- **Solution:** Send clarification request via Fiverr message before starting work

**Problem:** Can't match client's visual style
- **Solution:** Ask for reference images or mood board from client

**Problem:** Prompts aren't generating consistent results
- **Solution:** Add more specific technical details (lighting, camera angle, color temperature)

**Problem:** Client wants revisions
- **Solution:** Update Notion entry, revise specific prompts, re-export PDF
