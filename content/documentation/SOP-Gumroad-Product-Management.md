# SOP: Gumroad Product Management

**Title:** Gumroad Product Launch and Maintenance
**Owner:** [ME]
**Version:** 1.0
**Frequency:** MONTHLY (or AS NEEDED for new products)

---

## 1. Purpose
Launch and maintain Gumroad products (Mac & Mary Prompt Vault) with professional listings, customer support, and regular updates.

---

## 2. Prerequisites
- Gumroad account with payment processing configured
- Mac & Mary Prompt Vault ZIP package ready
- Notion templates included in package
- Marketing materials (social posts, email templates)
- Stripe or PayPal account connected

---

## 3. Step-by-Step Instructions

### Phase 1: Product Setup (30 minutes)
1. Log in to Gumroad
2. Create new product
3. Set product name: "The Mac & Mary Prompt Vault"
4. Set pricing: Launch price $47 (regular $67)
5. Configure payment options: Credit card, PayPal, Apple Pay, Google Pay
6. Set download type: Instant download
7. Upload ZIP file with proper structure
8. **Time estimate:** 30 minutes

### Phase 2: Listing Optimization (20 minutes)
1. Write compelling description using Gumroad Starter Kit template
2. Add product cover image (1280x769px recommended)
3. Set categories: Design Templates, AI Tools, Video & Animation
4. Add tags: AI prompts, Midjourney, Kling 2.0, character design
5. Enable comments and reviews
6. Set max downloads to unlimited
7. **Time estimate:** 20 minutes

### Phase 3: Marketing Launch (45 minutes)
1. Schedule social media posts (Instagram, TikTok, LinkedIn)
2. Send launch email to email list
3. Post in relevant communities (Reddit, Discord)
4. Share on personal social media accounts
5. Monitor initial sales and feedback
6. **Time estimate:** 45 minutes

### Phase 4: Customer Support (ONGOING)
1. Check Gumroad messages daily
2. Respond to purchase confirmations
3. Answer technical questions promptly
4. Send feedback request emails after 7 days
5. Document common issues for FAQ updates
6. **Time estimate:** 15 minutes daily

### Phase 5: Product Updates (MONTHLY)
1. Review customer feedback
2. Identify improvement opportunities
3. Add new prompts or features
4. Update ZIP package
5. Notify existing customers of updates
6. Consider pricing adjustments
7. **Time estimate:** 60 minutes monthly

---

## 4. Troubleshooting

**Problem:** ZIP file won't upload
- **Solution:** Check file size (Gumroad limit is 1GB), compress further if needed

**Problem:** Customers can't download
- **Solution:** Check link expiration settings, set to "Never expire"

**Problem:** Low conversion rate
- **Solution:** Update description, add more social proof, adjust pricing

**Problem:** Payment processing fails
- **Solution:** Check Stripe/PayPal account status, verify payout settings
