## 1. Purpose
Maintain organized character database, content calendar, and task tracking to scale production and deliver consistent client work.

## 2. Prerequisites
- Notion account (free tier works)
- Character Database CSV imported
- Content Calendar CSV imported
- Task List CSV imported

---

## 3. Step-by-Step Instructions

### Phase 1: Weekly Review (15 minutes)
1. Open Notion workspace
2. Review Content Calendar for upcoming week
3. Check Task List for overdue items
4. Review Character Database for new client characters
5. Identify bottlenecks or missing information
6. **Time estimate:** 15 minutes

### Phase 2: Content Calendar Updates (20 minutes)
1. Update status of completed content pieces
2. Add new content ideas to calendar
3. Set due dates for upcoming production batches
4. Tag content by platform (TikTok, Reels, YouTube)
5. Link content to relevant characters
6. **Time estimate:** 20 minutes

### Phase 3: Task List Maintenance (15 minutes)
1. Mark completed tasks as "Done"
2. Add new tasks from client orders or initiatives
3. Update priority levels based on deadlines
4. Assign tasks to yourself or team members
5. Set realistic due dates
6. **Time estimate:** 15 minutes

### Phase 4: Character Database Updates (20 minutes)
1. Add new client characters from Fiverr orders
2. Update character status as they progress through workflow
3. Add new Mac & Mary variations as needed
4. Export database as CSV for backup
5. Store backup in `/Users/jypsee72/Desktop/T.Zi.zu/notion-exports-backup/`
6. **Time estimate:** 20 minutes

### Phase 5: Weekly Backup (5 minutes)
1. Export all three databases as CSV
2. Save to project backup folder
3. Verify files are accessible
4. Note any export errors
5. **Time estimate:** 5 minutes

---

## 4. Troubleshooting

**Problem:** CSV export fails
- **Solution:** Check Notion account permissions, reduce data size if needed

**Problem:** Database views are not updating
- **Solution:** Refresh Notion page, check filter settings

**Problem:** Can't find a character entry
- **Solution:** Use search function, check different views (Gallery vs Table)

**Problem:** Task list is overwhelming
- **Solution:** Filter by priority, focus on High priority items first
