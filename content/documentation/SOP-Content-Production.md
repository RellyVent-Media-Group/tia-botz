# SOP: 90-Minute Content Production Batch

**Title:** 90-Minute Content Production Batch
**Owner:** [ME]
**Version:** 1.0
**Frequency:** DAILY (or as needed)

---

## 1. Purpose
Produce 10 consistent character videos in 90 minutes using the Mac & Mary Prompt Vault system.

---

## 2. Prerequisites
- Mac & Mary Prompt Vault (25 prompts downloaded)
- Midjourney v6/v7 account
- Kling 2.0 account
- Video editing software (CapCut, DaVinci, or similar)
- Notion workspace with Character Database and Content Calendar
- Stable internet connection

---

## 3. Step-by-Step Instructions

### Phase 1: Generate Images (0-20 minutes)
1. Open Mac & Mary Prompt Vault document
2. Select 5 prompts from the category you need (Mac, Mary, or Duo)
3. Copy each prompt to Midjourney
4. Generate images with `--cref` parameter for character consistency
5. Save all 5 images to a dedicated folder
6. **Time estimate:** 20 minutes

### Phase 2: Animate with Kling (20-50 minutes)
1. Open Kling 2.0
2. Upload each Midjourney image as reference
3. Add "consistent character" to each prompt
4. Generate 2 versions of each image (10 total videos)
5. Download all videos to your project folder
6. **Time estimate:** 30 minutes

### Phase 3: Export & Trim (50-70 minutes)
1. Open video editing software
2. Import all 10 videos
3. Trim to optimal length (15-30 seconds each)
4. Add watermark or brand overlay
5. Export in 1080p format
6. **Time estimate:** 20 minutes

### Phase 4: Write Captions (70-90 minutes)
1. Open Notion Content Calendar
2. Create entries for each video
3. Write captions using the formula: Hook + Value + CTA
4. Add relevant hashtags from brand template
5. Schedule or queue for posting
6. **Time estimate:** 20 minutes

---

## 4. Troubleshooting

**Problem:** Character looks different in each frame
- **Solution:** Use Midjourney `--cref` parameter with the same reference image for all generations

**Problem:** Kling animation quality is low
- **Solution:** Increase prompt detail, add "cinematic" and "high quality" to prompt

**Problem:** Videos won't export
- **Solution:** Check file format compatibility, reduce resolution if needed

**Problem:** Caption formula isn't working
- **Solution:** Reference the Fiverr Starter Kit script examples for proven formulas
