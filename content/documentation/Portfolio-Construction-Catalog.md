# Gilded Mirrors Originals – Portfolio Construction Catalog

## A Comprehensive How‑To Guide for Building Visual Assets Across All Souls, Entities & AGENTS

---

### 1. Introduction

This catalog walks you through the **complete portfolio construction pipeline** for the **Gilded Mirrors Originals** universe. You'll learn how to generate consistent, high‑quality visual assets for every **AGENT**, **Entity**, and **Soul** using a structured set of shot‑type templates.

We define **five core shot types** – each serving a distinct narrative and branding purpose:

| # | Shot Type | Purpose |
|---|-----------|---------|
| **#1** | **Classic Hook Face** | The definitive "first impression" portrait. Used for character intros, billing blocks, and hero placements. |
| **#2–6** | **Over Dramatic / Epic / Funny** | High‑energy, exaggerated expressions that showcase personality, humor, and emotional extremes. |
| **#7–11** | **Trust‑Building Warmth** | Approachable, relatable, and humanising shots that build audience connection and empathy. |
| **#12–16** | **Branding Hero Shot** | Polished, aspirational images that position the character as a symbol of the brand – powerful, iconic, and memorable. |

> **Note:** The numbering above is for reference only; you can apply any shot type to any character.

---

### 2. The Portfolio Construction Workflow

Follow these seven steps to build a complete, cross‑platform portfolio for all characters.

#### Step 1 – Define the Character

Collect all canonical data for the character:
- **Name, Archetype, Realm, Domain**
- **Signature Hook** (their defining line)
- **Personality Traits & Hidden Depths**
- **Associated Souls & Entities**
- **Visual Identity Notes** for each universe (Muppet/Puppet, Barbie‑like, Action Figure, Photo‑realistic)

#### Step 2 – Choose the Shot Type Portfolio

For each character, you will generate **at least one image for each of the five shot types**. This ensures versatility for social media, press kits, merchandise, and storytelling.

#### Step 3 – Craft the AI Prompt

Use the **prompt templates** provided below. Each template includes:
- **Character description** (age, ethnicity, build, attire, accessories)
- **Environment & lighting** (to match the shot type)
- **Emotion & expression** (key to the shot's purpose)
- **Style & quality instructions** (cinematic, photorealistic, etc.)
- **Negative prompt** (to avoid common AI artifacts)

#### Step 4 – Generate in Batch

Run the prompts through your preferred AI image generation tool (Midjourney, DALL‑E, Stable Diffusion). Generate multiple variations and select the best.

#### Step 5 – Post‑Process

Refine selected images:
- **Remove artifacts** (extra fingers, distorted faces)
- **Adjust lighting and contrast**
- **Add subtle branding** (watermarks, colour grading) if needed
- **Crop** to platform‑specific ratios (1:1 for Instagram, 16:9 for banners, 4:5 for vertical social)

#### Step 6 – Organise the Portfolio

Create a folder structure:
```
Portfolio/
├── AGENTS/
│   ├── Delta_Drill/
│   │   ├── 01_HookFace.png
│   │   ├── 02_OverDramatic.png
│   │   ├── 03_Epic.png
│   │   ├── 04_Funny.png
│   │   ├── 05_TrustWarmth.png
│   │   └── 06_BrandingHero.png
│   └── ...
├── ENTITIES/
└── SOULS/
```

#### Step 7 – Deploy Across Platforms

Use the portfolios for:
- **Social media** (profile pics, posts, stories)
- **Website/landing pages**
- **Press kits and pitch decks**
- **Merchandise** (prints, stickers, apparel)
- **Video thumbnails and lower‑thirds**

### 4. Constructing the Full Portfolio – All Souls, Entities & AGENTS

Now that you have the shot‑type templates, here's how to build a **complete portfolio** for every character.

#### Step 1 – Inventory All Characters

Compile a master list of all **AGENTS** (8 Gilded Mirrors Originals) and **Entities** (25+) and **Souls** (40+). For Souls, which are abstract essences, you may use symbolic visual representations (e.g., glowing orbs, patterns, ethereal humanoids).

#### Step 2 – Assign Shot Types Per Character

For each character, you will generate **at least 5 shots** (Classic Hook, Epic, Warm, Hero, plus one expressive shot). For key characters (Mac, Mary, the Gilded Mirrors Originals), you may want multiple variations per shot type.

#### Step 3 – Generate Prompts Using Templates

Use the templates provided above, replacing the bracketed placeholders with character‑specific details. For Entities, you may need to adapt the descriptions – for example, **Babelonia Nocturne** (Crypto Sorceress) might have a blockchain‑themed background, while **Zupa Nova** (Cosmic Mystic) would have starry skies.

#### Step 4 – Batch Generation & Curation

For each character, generate 20–50 images per shot type, then curate the best 5–10 final assets.

#### Step 5 – Cross‑Universe Variations

Remember that each character appears in **four visual styles** (Muppet/Puppet, Barbie‑like, Action Figure, Photo‑realistic). Your portfolio should include **at least the Photo‑realistic version** for social media, but you can also generate the other styles for platform‑specific branding.

#### Step 6 – Create a Portfolio Guide

For each character, create a **style guide** that includes:
- Character name, archetype, and canonical signature
- Preferred colour palette
- Preferred shot types with sample images
- Dos and Don'ts (e.g., "Don't show Mary without her smart glasses" or "Mac always has his notebook visible")

#### Step 7 – Package for Delivery

Organise all assets into a structured folder, with a master spreadsheet mapping each image to shot type, universe, and usage.

### 6. Advanced Tips

- **Consistency:** Use the same character prompt base and only change the action, emotion, and lighting to maintain facial and body consistency.
- **Negative Prompts:** Always include a negative prompt to avoid extra limbs, distorted faces, unrealistic lighting, or text.
- **Colour Grading:** Establish a brand LUT (Look‑Up Table) – Gilded Mirrors uses warm golds, teal accents, and deep shadows.
- **Batch Processing:** Use tools like Automatic1111 (Stable Diffusion) with batch files to generate multiple images with varying seeds.
- **Quality Threshold:** Discard any image with obvious artifacts; use upscaling (e.g., Topaz Gigapixel) for final output.
